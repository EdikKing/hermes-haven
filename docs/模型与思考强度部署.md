## 使用

- 点击“新建会话”或“开始新会话”，先选择模型与思考强度，再创建会话。
- 输入框下方的模型和思考强度可修改，自动按会话保存，下一条消息生效。正在运行或待核对的原请求继续沿用提交时的选择。
- 选择“默认”时沿用 Hermes 默认设置。明确不支持思考的模型会禁用强度选择。
- 更新后需要重新登录；页面仍是旧版本时使用 Ctrl+F5 刷新。
