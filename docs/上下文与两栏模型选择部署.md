## 数据来源

`GET /api/sessions/{id}/context` 要求登录，通过 Hermes 自带的只读 `SessionDB`、`query_only=ON` 和只读事务读取有效上下文。优先采用通过一致性验证的 usage anchor；不可用时统计有效消息与已保存的系统提示，不把累计计费 token 当作当前上下文。工具定义等未保存开销可能不包含在消息统计中。

模型容量依次读取适用的配置、端点缓存及本机模型目录；目录查询禁止联网。Codex 等 Hermes 明确跳过持久缓存的路由同样跳过，避免旧的 272k 缓存覆盖当前模型目录。没有足够信息时显示容量未知或剩余量待统计。

统计随选择会话、切换模型及本轮结束更新，并在运行期间定时读取。返回值仅含计数、模型标识及来源，不返回历史正文、系统提示、供应商地址或认证信息。不修改 Hermes 配置或历史数据库。
